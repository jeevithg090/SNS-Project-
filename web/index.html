How it works

  1. Count per IP

    Each source IP gets a one-second window. Every SYN packet in that window increments its counter.

  2. Rate-limit

    Packets beyond the rate limit are dropped and each one counts as a violation against that IP.

  3. Ban

    When an IP's violations reach the ban threshold, every later packet from it is blocked for the rest of the session.

Four legitimate hosts send one packet every 0.8 s throughout, so they never trip the limit. Seven attacker IPs share the flood. Everything runs locally; no packets leave your browser.
